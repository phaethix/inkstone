# Historical plans and specs

This directory keeps completed feature plans/specs so we can recover the
constraints, acceptance criteria, and implementation context of the time.

They are **not** the authoritative source for the current product direction:

- Released / local-prototype / planned status: [`../ROADMAP.md`](../ROADMAP.md)
- Remote Colab operations: [`../guides/colab-cli.md`](../guides/colab-cli.md)

Do not copy superseded architecture constraints from historical specs (for
example the old D2 PageScript gate) into new work. Check current code and the
roadmap first.
