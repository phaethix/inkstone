# 漫画成品设计：排版 / 人物 / 风格 三层解耦

日期：2026-11-06
决策：由 With 智能体自主定方案，用户只要结果

## 为什么这样设计

前几轮连续出现字泡、多画一人、线稿人物、串场景、脑袋出框。根因经
systematic-debugging 查清：finished_page 模式让免费 flash 模型一次把整页
多格画成一张位图，分镜边界、上色、人数、风格全靠自然语言约束，扩散模型
守不住几何边界，于是反复翻车。继续加负向词已被证明无效（负向里禁线稿/禁书的
词一个都没被遵守）；简单切 panel_compose 虽能根治出框，但其 LayoutEngine
是固定等分网格，并不美观。

因此把三个目标拆到各自最擅长的层，从根上分开：

| 目标 | 交给谁 | 约束类型 |
| --- | --- | --- |
| 排版美观 | 程序（PIL 画 gutter / 边框 / 分镜） | 几何硬约束 |
| 人物一致 | 同一套角色肖像作参考 + 统一角色描述 | 参考图 + 同一画布 |
| 风格可指定 | 统一的 STYLE 常量注入每幅生成 | 参数化，一处改全本 |
| 纯图无字 | 模型不画任何文字/边框，导出纯图 | 延续既有硬约束 |

关键简化：每页 = 一张统一风格单幅主视觉 + 程序化裁切分镜。同一页所有分镜
物理上来自同一张图，因此人物/画风/场景天然 100% 一致；边界由代码精确绘制，
模型完全不碰排版，出框、线稿 inset、串场、多画人等失败源被一次性消除。

## 交付物

- comic_out/art_v2/scene_01..04.png：四幅统一风格主视觉（无边框/无字/无线稿）。
- scripts/assemble_comic.py：可复现排版脚本，程序画分镜、产出纯图 PDF。
- comic_out/pages_v2/page_01..04.png：程序化排版后的四页。
- comic_out/comic.pdf：最终成品，4 页 A4 比例（595x842pt），纯图、无字泡。

## 风格怎么指定（用户诉求）

打开 assemble_comic.py 改 STYLE 一个常量即可（或后续接 CLI --style）。该串是
每幅主视觉生成的统一前缀；四幅 scene_*.png 用同一风格串 + 同一两张角色肖像
参考生成，所以换风格时全本画风会一致地变化，人物长相不漂移。

## 排版怎么保证美观

LAYOUTS 是每页的分镜矩形（归一化坐标），程序按 MARGIN_RATIO / GUTTER_RATIO /
BORDER 精确画出留白、间隔、边框，节奏刻意变化：P1 大横幅+双联、P2 竖幅双联、
P3 三横条、P4 大小对比。图像用 cover-fit 贴合且主体居中，不裁脸；每格都来自
同一主视觉，故无跨格不一致。

## 验证

- 四幅主视觉 + 最终 PDF 均已肉眼验收：风格统一、人物一致、无字泡/无线稿/无出框。
- 全量 uv run pytest 全绿；uvx ruff format / ruff check 通过（已按仓库
  test_comment_style 规则去掉分节横幅注释）。
- 旧成品仍保留在 comic_out/pages/ 与 pages/blank/，可随时恢复；本方案未删除
  或改动既有代码路径，新增脚本与产物为独立目录。

## 边界 / 诚实说明

- 这是离线成品组装方案，不改动 Inkstone 主生成流水线；四幅主视觉用
  generate_picture 基于既有角色肖像生成，风格串在脚本里固化。若要接入流水线
  让 --fresh 自动产出同样效果，属后续工程化。
- 风格指定的粒度是全本统一风格；若要按页/按角色指定不同风格，需扩展。
- 本轮未 commit（按用户习惯）。
