设计思路

在无 GPU、只用免费 Agnes 的硬约束下，做到可用的角色一致性

把一致性拆成三层可工程化策略，每层各司其职

01

L1 提示词硬描述

自动抽取角色外貌、服饰、场景，并把完整描述内嵌到每个分镜 prompt。身份不依赖参考图，零额外 API 成本。

02

L2 参考图 img2img

先生成角色立绘，后续分镜把「立绘 + 上一格」同时作为 Agnes 多图参考输入，辅助保持身份稳定。

03

可续跑 + 容错

state.json 断点续跑、503 耐心重试、内容安全跳过，让长小说生成不惧怕网络抖动。
