技术亮点

      
围绕一致性、可靠性、低成本三个核心问题设计

    

    

      

        
📝

        
L1 提示词硬描述

        
自动抽取角色外貌、服饰、场景，并把详细描述内嵌到每个分镜 prompt 中，降低对参考图的依赖。

      

      

        
🖼️

        
L2 参考图 img2img

        
先生成角色立绘，再把立绘 + 上一格分镜同时作为 Agnes 多图参考输入，辅助保持身份一致。

      

      

        
🛡️

        
可续跑 + 容错

        
state.json 断点续跑、免费档 503 耐心重试、内容安全跳过，让长小说生成不惧怕网络抖动。
